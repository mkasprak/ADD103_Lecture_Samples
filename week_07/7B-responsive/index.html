💡 What Are Media Queries & How Do They Work?

1. The Simple Analogy

Imagine dressing for the weather. If it's hot outside, you wear a t-shirt. If it starts raining, you put on a raincoat. Media queries work the same way for websites! They ask the browser: "How wide is this screen right now?" Based on the answer, the browser applies different CSS styling rules.

2. Why "Mobile-First"?

In modern web development, we usually write CSS mobile-first:

  • Base CSS (Default): Write styles for mobile screens first (e.g., a simple 1-column layout).
  • Media Queries: As the screen gets wider (tablets, laptops, desktops), media queries kick in to expand the layout into 2 or 4 columns.

3. Anatomy of a Media Query

Here is what the code looks like in your CSS file:

/* 1. Base styles (apply to mobile phones by default) */
.card-container {
    display: grid;
    grid-template-columns: 1fr; /* 1 Column */
}

/* 2. Tablet view: triggers at 600px width or wider */
@media (min-width: 600px) {
    .card-container {
        grid-template-columns: 1fr 1fr; /* 2 Columns */
    }
}

/* 3. Desktop view: triggers at 900px width or wider */
@media (min-width: 900px) {
    .card-container {
        grid-template-columns: repeat(4, 1fr); /* 4 Columns */
    }
}

4. The Secret Ingredient: Viewport Meta Tag

Media queries won't work on mobile devices without this required line inside your HTML <head>: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Without it, phone browsers pretend to be desktop screens and zoom out, making your site tiny and unreadable!

5. How to Test It Yourself

  • Resize your window: Click and drag the corner of your browser window to make it wider or narrower. Notice how the background color changes from grey (mobile) to blue (tablet) to green (desktop)!
  • Use Developer Tools: Press F12 or right-click → Inspect, then click the Device Toolbar icon (📱) to test specific phone models.
