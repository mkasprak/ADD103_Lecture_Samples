💡 How Media Queries & Visibility Classes Work

1. What is a Media Query?

A media query is a CSS rule that tests browser conditions—most commonly screen width—and applies CSS styles only when those conditions are met. Think of it like a smart switchboard for your website!

2. The 3 Standard Breakpoints

  • 📱 Mobile (< 600px): Default base styles (no media query needed for Mobile-First!).
  • 📲 Tablet (600px – 899px): Triggered by @media (min-width: 600px).
  • 💻 Desktop (900px+): Triggered by @media (min-width: 900px).

3. How Background Colors Change Across Breakpoints

We change the background-color of the body element inside each breakpoint's media query block:

/* 📱 Mobile default background */
body {
    background-color: #f4f0fa;
}

/* 📲 Tablet background at 600px */
@media (min-width: 600px) {
    body {
        background-color: #e3f2fd;
    }
}

/* 💻 Desktop background at 900px */
@media (min-width: 900px) {
    body {
        background-color: #fff8e1;
    }
}

4. How We Show/Hide Text at Specific Breakpoints

To show text only at a specific breakpoint and turn it invisible everywhere else, we combine display: none and display: block:

  1. Start by hiding non-mobile classes: On mobile default, set .show-tablet and .show-desktop to display: none, and set .show-mobile to display: block.
  2. Switch visibility in Tablet Media Query (600px): Hide .show-mobile and .show-desktop (display: none), and show .show-tablet (display: block).
  3. Switch visibility in Desktop Media Query (900px): Hide .show-mobile and .show-tablet (display: none), and show .show-desktop (display: block).
/* 📱 Mobile Default */
.show-mobile { display: block; }
.show-tablet { display: none; }
.show-desktop { display: none; }

/* 📲 Tablet View (600px+) */
@media (min-width: 600px) {
    .show-mobile { display: none; }
    .show-tablet { display: block; }
    .show-desktop { display: none; }
}

/* 💻 Desktop View (900px+) */
@media (min-width: 900px) {
    .show-mobile { display: none; }
    .show-tablet { display: none; }
    .show-desktop { display: block; }
}
