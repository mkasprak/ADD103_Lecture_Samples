CSS Selectors: Element vs. Class

This page demonstrates how global element (tag) selectors style everything of that type, and how class selectors target specific elements.

1. Global Element Selectors

This box uses global CSS selectors targeting tags (like h2, p, and a) directly. Every single matching tag on the website gets these styles:

  • h2 is styled dark gray
  • p is styled medium gray
  • a is styled blue and underlined

For example, this standard link: W3Schools Home receives the default underlined blue color styling because it uses the plain <a> tag.
