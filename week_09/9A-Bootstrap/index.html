📊 Look & Learn: The 12-Column Grid System

Bootstrap divides the screen into 12 equal vertical units. You combine units using classes like col-12, col-md-6, and col-lg-4.

Column 1

col-12 col-md-6 col-lg-4

Mobile: 100% | Tablet: 50% | Desktop: 33%

Column 2

col-12 col-md-6 col-lg-4

Mobile: 100% | Tablet: 50% | Desktop: 33%

Column 3

col-12 col-md-12 col-lg-4

Mobile: 100% | Tablet: 100% | Desktop: 33%
💡 Notice: Resize your browser window! At 768px (Tablet), Columns 1 & 2 sit side-by-side while Column 3 spans full width below them. At 992px (Desktop), all 3 columns align into a single row!

💡 How Bootstrap 5 & The Grid System Work

1. What is a CSS Framework?

Up to now, you wrote custom CSS rules and media queries from scratch. A CSS Framework like Bootstrap 5 provides pre-written CSS classes created by professional web developers. You simply link the framework and apply class names directly to your HTML elements!

2. Connecting Bootstrap via CDN

Instead of downloading large CSS files into your project folder, you paste a single CDN (Content Delivery Network) link inside your <head>: 

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

3. The Container → Row → Column Nesting Rule

To build a grid layout in Bootstrap, you MUST follow this strict 3-tier nesting structure:

  1. .container: Sets a centered, responsive bounding frame on the page.
  2. .row: Placed directly inside .container. Activates Flexbox and holds column items.
  3. .col-*: Placed directly inside .row. Holds your content (cards, images, text).

4. Understanding the 12-Column Grid Math

Bootstrap divides every row into 12 units. Your column classes specify how many units an item consumes across screen breakpoints:

  • col-12: Spans 12 out of 12 units (100% full width — default on mobile screens).
  • col-md-6: Spans 6 out of 12 units (50% half width on Medium screens ≥768px — tablets).
  • col-lg-4: Spans 4 out of 12 units (33.3% one-third width on Large screens ≥992px — desktops).
<!-- Example 3-column responsive card wrapper -->
<div class="container">
    <div class="row">
        <div class="col-12 col-md-6 col-lg-4">
            <!-- Card Content Here -->
        </div>
    </div>
</div>

5. Essential Bootstrap Utility Classes

Class Name What It Does
img-fluid Makes an image responsive (max-width: 100%; height: auto;)
border / rounded Adds a subtle border and rounded corners to boxes or images
shadow-sm Applies a subtle drop-shadow elevation to cards
p-3 / my-4 / g-4 Spacing utilities for padding (p), vertical margins (my), or grid gaps (g)
text-center Horizontally centers text alignment
