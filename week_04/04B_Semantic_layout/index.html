What is <aside>?

Think of a magazine sidebar: related to the article, but not essential to the main story. An <aside> could hold quick tips, related links, a pull quote, or a glossary. Here it is floated right so the main content wraps around it.

How does float work?

float: right removes an element from the normal document flow and pushes it to the right edge of its container. Other content then wraps around its left side â€” exactly like a photo caption in a newspaper column.

The parent element needs overflow: hidden (set on main in styles.css) to "contain" the float, otherwise the parent collapses to zero height and the floated element sticks out below it.
